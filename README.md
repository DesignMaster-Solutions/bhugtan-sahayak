# Bhugtan Sahayak

Free, open-source helper for people in India whose government payment did not arrive: a PM-KISAN
installment, a pension, MGNREGA wages, a scholarship or a subsidy that was approved but never
reached the bank account, stopped, or went to another account. In a few questions it shows the
most likely reason the Direct Benefit Transfer failed, the official way to check it, the fix and
where to do it, and a ready-to-show request in Hindi or English. It never asks for an Aadhaar,
bank account or phone number.

Status: **not built yet.** This repository holds the scope (`BRIEF.md`) for an entry in the
Code for a Billion 2026 hackathon, track Financial Inclusion. Every reason, check and fix the tool
will state is being checked against official sources (UIDAI, NPCI, PFMS, RBI, the scheme portals)
before it is coded; nothing here is advice yet.

Planned: static web app (English and Hindi, under 100 KB, no account, no cookies), rule engine
with tests, anonymous public usage counter at `/stats`.
